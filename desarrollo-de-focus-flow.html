DESARROLLO DE FOCUS FLOW

PROMT GENERADO POR CHATGPT

Le pedí a ChatGPT que me hiciera un prompt para luego enviárselo a Gemini. 

Lo que solicitamos fue lo siguiente: 

Necesito que me hagas un prompt para enviarselo a gemini. Quiero una aplicacion web, es un Pomodoro. Quiero que sea una aplicacion web que se adapte en todos los dispositivos, tanto en movil, tablet como ordenador. Quiero que incorpore las mejores características de los pomodoros que sean más populares. También, quiero que hayan varios temas de personalización, quiero tonos pasteles. Por otro lado, quiero que haya un apartado donde el usuario pueda escribir sus tareas pendientes, y luego seleccionar en el pomodoro esa tarea para concentrase y hacer esa tarea. Luego quiero que

también, haya un apartado donde puedan estudiar varios usuario compartiendo un enlace de invitación, cada uno con su pomodoro. También el usuario podrá crear una sala de estudio, quiero que esto funcione de verdad, y que pueda compartir el enlace de invitación de la sala de estudio. Si un usuario termina antes que el resto de sus compañeros, como premio, tendrá más tiempo de descanso. A su vez, también se visualizará el estado en el que está cada uno de los usuarios (estudiando, descansando, inactivo). También, quiero que haya un apartado donde el usuario pueda configurar cuantas sesiones quiere estudiar, cuanto tiempo, y cuanto tiempo de descanso. También quiero que en ese mismo apartado haya un calendario para que el usuario pueda gestionar sus sesiones de estudio, por ejemplo, en el mes de octubre, el martes el usuario estudio en total 50 min en x sesiones. Es muy importante que no se utilicen iframes. 

A lo que ChatGPT nos dió un prompt inicial: 

🧠 PROMPT PARA GEMINI

Quiero que desarrolles una aplicación web completa tipo Pomodoro, con las siguientes características y requisitos:

🎯 OBJETIVO GENERAL

Desarrollar una aplicación web responsive (adaptable a móvil, tablet y ordenador) que implemente la técnica Pomodoro, con un enfoque moderno, colaborativo y personalizable.

💡 FUNCIONALIDADES PRINCIPALES

  1. Pomodoro Timer Principal

    • Temporizador con configuración de tiempo de enfoque y descanso.

    • Sonido o alerta al finalizar cada sesión.

    • Contador visual (barra circular o progresiva).

    • Opción de pausar, reiniciar o saltar sesión.

    • Interfaz limpia y minimalista con tonos pastel.

  2. Personalización de Temas

    • Varios temas de color con paletas de tonos pastel (azul suave, verde menta, lavanda, rosa pálido, beige, etc.).

    • El usuario puede cambiar el tema desde la configuración.

  3. Gestor de Tareas Pendientes

    • Apartado donde el usuario puede crear, editar, eliminar y marcar tareas.

    • Cada tarea puede ser asociada a una sesión de Pomodoro, para enfocar la concentración en esa tarea concreta.

  4. Estudio Colaborativo (Salas de Estudio)

    • El usuario puede crear una sala de estudio y obtener un enlace de invitación para compartirlo con otros usuarios.

    • Cada usuario tiene su propio Pomodoro individual.

    • El sistema mostrará el estado actual de cada usuario:

      • Estudiando

      • Descansando

      • Inactivo

    • Si un usuario termina antes que los demás, obtiene tiempo adicional de descanso como recompensa.

    • La sincronización debe ser en tiempo real (por ejemplo, usando WebSockets o Firebase).

    • No se deben usar iframes en ningún caso.

  5. Configuración Avanzada

    • El usuario puede personalizar:

      • Duración de las sesiones de estudio.

      • Duración de los descansos cortos y largos.

      • Número de sesiones antes de un descanso largo.

  6. Calendario y Estadísticas

    • Un calendario mensual donde el usuario puede ver sus sesiones de estudio completadas.

    • Ejemplo: “El martes 8 de octubre estudió 50 minutos en 3 sesiones.”

    • Registro histórico de productividad.

🧩 REQUISITOS TÉCNICOS

  • Diseño responsive (que se adapte perfectamente a móviles, tablets y ordenadores).

  • No usar iframes bajo ningún concepto.

  • Usar tecnologías web modernas:

    • Frontend: React, Vue o Svelte (elige una moderna y eficiente).

    • Backend: Node.js, Express o Firebase.

    • Base de datos: Firestore, MongoDB o similar.

  • Para la colaboración en tiempo real, usar WebSockets o Firebase Realtime Database.

  • Estilo visual: tonos pastel, estética limpia, minimalista y con buena experiencia de usuario.

  • Implementar autenticación de usuario básica (email o Google).

🏆 EXTRA

  • Incluir animaciones suaves (por ejemplo, con Framer Motion o CSS transitions).

  • Modo claro y oscuro.

  • Notificaciones cuando termine el Pomodoro o el descanso.

  • Sonidos personalizables.

📦 RESUMEN

Crea una aplicación web Pomodoro totalmente funcional, colaborativa, personalizable y moderna, con un diseño pastel y una experiencia de usuario fluida, sin usar iframes.

Sin embargo, quería crear un apartado específico para que el usuario pudiera estudiar en una sala de estudio con otros amigos mediante un enlace de invitación, se lo comuniqué a ChatGPT y me dio lo siguiente para complementarlo con el prompt anterior: 

Aquí te pongo un ejemplo de cómo reformular esa sección del prompt para asegurarte de que Gemini lo genere:

🔹 Sección específica de invitaciones a salas de estudio

  • Crear un apartado exclusivo en la aplicación llamado “Invitar a Sala de Estudio”.
  • En este apartado, el usuario puede:
    1. Generar un enlace único para la sala que ha creado.
    2. Copiar el enlace al portapapeles con un botón claramente visible.
    3. Compartir el enlace directamente (por ejemplo, por WhatsApp, correo o redes sociales).
  • Este apartado debe ser independiente de otras funciones, como la visualización de usuarios o el Pomodoro individual.
  • El enlace debe permitir que otros usuarios se unan directamente a la sala de estudio con su propio Pomodoro.
  • El sistema debe mostrar en tiempo real el estado de los usuarios en la sala (estudiando, descansando, inactivo).
  • No usar iframes; toda la funcionalidad debe estar integrada en la aplicación web.

💡 Tip para Gemini: Cuando pegues el prompt completo, asegúrate de poner algo como:

“Es muy importante que haya un apartado exclusivo para invitar a otros usuarios a la sala de estudio, con generación y compartición de enlace, separado de otras funcionalidades.”

PROTOTIPOS GENERADOS POR GEMINI AI PRO

VERSIÓN OFICIAL DE FOCUS FLOW

Se obtuvieron 6 prototipos de Focus Flow, siendo el sexto prototipo el definitivo para seguir desarrollándolo. 

Se eligió principalmente por la primera impresión que generó a simple vista, ya incorporaba algunos apartado que habíamos solicitado a Gemini, y la interfaz resultó ser muy a mi gusto.

Contaba con los apartados Temporizador, Estadísticas y Ajustes. A continuación vamos a desglosar brevemente cada uno:

1. Temporizador: es la página principal que el usuario va a ver. Consta del Pomodoro, Tareas Pendientes y si ha iniciado sesión, la Sala de Estudio donde puede estudiar con amigos (esto lo explicaremos más adelante).

2. Estadísticas: es un calendario mensual donde el usuario puede ver cuántas sesiones de estudio ha hecho, a la vez, puede añadir tareas para cualquier día.

3. Ajustes: aquí se puede configurar las sesiones de estudio, el tiempo de estudio y el tiempo de descanso (Descanso Corto/Descanso Largo).

Sin embargo, se me ocurrió la idea de que el usuario pudiera estudiar en una sala de estudio con amigos mediante un enlace de invitación, con 2 opciones de envío directos: Whatsapp y Correo. Pero quería que esto fuera una opción exclusiva, así que en vez de hacerla de pago solamente se exige que el usuario inicie sesión, y ya con eso, puede disfrutar de esta función, que a mi parecer, puede motivar aún más y competir entre sí sanamente.  Por tanto, le pedí a Gemini que incorporara un nuevo apartado para que el usuario pudiera iniciar sesión, creando así un nuevo apartado, Perfil. 

4. Perfil: se puede ver el correo del usuario, también tiene disponible la configuración de idioma. Por otro lado, puede habilitar según prefiera las notificaciones.

 

Actualización: no me percaté que el código empezaba por import reacts, cosa que cuándo lo intente poner en el index.html en Git Hub. Así que le pedimos a Gemini que nos modificara el código y lo ajustara a html. 

El código que nos proporcionó simplificó bastante la interfaz de Focus Flow, incluso, quitó el apartado de Estadísticas, y otras animaciones estéticas que motivaban al usuario. Quedando así el resultado final:
