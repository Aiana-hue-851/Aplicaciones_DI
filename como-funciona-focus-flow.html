CÓMO FUNCIONA FOCUS FLOW

Focus Flow es un Pomodoro que se caracteriza por un estilo minimalista con las funciones necesarias para facilitar la concentración y motivar al usuario a seguir realizando sus tareas en el tiempo propuesto. 

Cuenta con varios apartados: 

  1. Temporizador: Se encuentra el Pomodoro a simple vista con un fondo prestablecido. Puede ver las sesiones de estudio, las sesiones de descanso corto o descanso largo. El usuario puede saltar sesiones o volver a reiniciarlas, según prefiera.
  2. Tareas Pendientes: con una interfaz bastante sencilla, el usuario puede añadir o eliminar tareas, así como previsualizar la tarea que quiere realizar en el Temporizador, y una vez terminada, puede marcar la tarea hecha.
  3. Ajustes: se puede configurar el tiempo de enfoque, el tiempo de descanso corto y de descanso largo, cuántas sesiones quiere realizar. Tiene también la posibilidad de configurar las notificaciones. Y por último, las animaciones de enfoque y de los descanso. También puede cambiar de idioma: español e inglés.

 

4. Perfil: el usuario puede iniciar sesión para personalizar su experiencia.
