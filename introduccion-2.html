Introducción

Para la tarea de crear una aplicación que permita al usuario sumerjirse en España y Pinto hemos desarrollado la una aplicación web "Descubre Pinto"

Esta aplicación permite al usuario conocer los aspectos más importantes y destacables que necesita conocer para una primera visita al país como para el pueblo. A su vez, se pretende despertar su interés para seguir curioseando sobre los aspectos que más le hayan podido gustar.
