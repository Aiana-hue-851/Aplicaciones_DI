A lo que ChatGPT, me dio la siguiente respuesta:

Empiezo con las primeras preguntas clave para entender el objetivo general y el alcance:

  1. ¿Cuál es la idea principal de la aplicación? (qué problema resuelve y para quién)

  2. ¿Quiénes son los usuarios objetivo? (perfil, nivel técnico, número estimado de usuarios)

  3. ¿Cuál es el caso de uso principal — la tarea que el usuario debe poder completar en menos pasos posible?

  4. ¿Necesitas roles o permisos distintos (por ejemplo: admin, editor, usuario, invitado)? Si sí, ¿qué puede hacer cada rol?

  5. ¿La app requiere autenticación? ¿Qué tipos (email/contraseña, SSO — Google/Apple/Empresa, OAuth, login sin contraseña)?

  6. ¿Qué datos principales va a manejar la app? (ej.: usuarios, productos, documentos, mensajes, imágenes — y volumen aproximado)

  7. ¿Necesita integrarse con otros servicios (p. ej. pago, CRM, API externas, almacenamiento, correo, analytics)? Di cuáles.

  8. ¿Qué funciones "must-have" (imprescindibles) y cuáles "nice-to-have" (deseables) para la primera versión (MVP)?

  9. ¿Qué plataformas debe soportar? (desktop web, mobile web, PWA, app nativa)

  10. ¿Requisitos de rendimiento/latencia o uso offline/latencia variable?

  11. ¿Privacidad/seguridad/legal relevantes? (GDPR, CCPA, cifrado, datos sensibles, autenticación multifactor)

  12. ¿Idiomas y localización? ¿Soporte multilenguaje necesario?

  13. ¿Preferencias visuales/branding? (colores, tono, ejemplos de apps que te gusten)

  14. ¿Necesitas accesibilidad (WCAG) a un nivel concreto?

  15. ¿Qué métricas te importan para medir éxito? (conversiones, retención, tiempo tarea, NPS, MAU/DAU)

  16. ¿Cuánto contenido dinámico habrá (notificaciones en tiempo real, colaboraciones en vivo)?

  17. ¿Necesitas panel administrativo o herramientas de moderación/soporte?

  18. ¿Requisitos de exportación/importación de datos (CSV, Excel, API)?

  19. ¿Cómo quieres manejar errores y feedback del usuario (toasts, modales, inbox de soporte)?

  20. ¿Planes de monetización? (suscripción, freemium, anuncios, pago por uso)

  21. ¿Qué flujos clave deberían diseñarse primero (registro, onboarding, flujo principal, pago, soporte)?

  22. ¿Tienes restricciones técnicas o stack preferido (React, Vue, backend, base de datos)?

  23. ¿Hay ejemplos de UX/UI que te parezcan ideales o que quieras evitar?

  24. ¿Necesitas tests automatizados, QA o entornos (staging, prod) desde el inicio?

  25. ¿Plazos o hitos importantes (lanzamiento MVP, demo inversores, feria, etc.)?

Dime si quieres que siga haciendo preguntas más detalladas por área (UX, UI visual, microinteracciones, copy, states de error, formularios, validaciones, etc.). Y recuerda: di “para” cuando quieras que deje de preguntar. ¿Con cuál de las preguntas quieres empezar a responder?

La aplicación es una guía turística avanzada del municipio de Pinto (España) y debe incluir traducción completa a varios idiomas, sistema de reservas, itinerarios y experiencia estilo iOS.

✅ 1. Requisitos generales

La aplicación debe ser:

  • Web

  • Responsive (Android + iOS + desktop)

  • Diseñada con estética iOS

  • Compatible como PWA (opcional)

  • Modo Claro / Modo Oscuro

  • Soporte multilenguaje completo

    • Español

    • Inglés

    • Italiano

    • Alemán

    • Francés

    • Ruso

    • Chino

Gemini debe generar un sistema que traduzca todas las secciones, botones, textos, mensajes, notificaciones, errores y formularios.

✅ 2. Secciones obligatorias de la aplicación

INICIO

  • Pantalla principal estilo iOS

  • Accesos a todas las secciones

PINTO

  • Información turística

ITINERARIOS

    • Lujo

  • Sugerencias dinámicas según tipo de turista

  • Crear, guardar y personalizar itinerarios (solo usuarios con sesión iniciada)

RESERVAS

Debe permitir reservar:

  • Hoteles en Pinto y España

  • Transportes

  • Tours

  • Entradas

REQUISITOS:

  • Filtros: precio, valoración, personas, tipo de alojamiento

  • Métodos de pago:

    • Tarjeta

    • Bizum

  • Sistema de pago seguro (elige el más lógico)

ESPAÑA

  • Guía cultural del país

  • Clima, moneda, costumbres

SALUD Y SEGURIDAD

  • Centros médicos cercanos

  • Teléfonos de emergencia

GUÍA DE MOVILIDAD

AJUSTES

  • Iniciar / cerrar sesión

  • Activar modo claro/oscuro

  • Configuraciones adicionales

✅ 3. Sistema de usuarios

Dos estados:

🔹 Usuario sin sesión:

  • No puede marcar favoritos

  • No puede guardar itinerarios

  • No puede escribir reseñas

  • No puede acceder a “Mi Lista”

🔹 Usuario con sesión iniciada:

  • Tiene acceso a todas las funciones

  • Puede guardar itinerarios

  • Puede marcar favoritos

  • Puede escribir reseñas
